# Общая фотография тренажёра

Тренажёр загружает опубликованный файл `images/reward.jpg`. Все участники видят эту фотографию; выбирать свои изображения в публичном тренажёре нельзя.

Владелец `vs363ru` может открыть [управление фотографией](https://vs363ru.github.io/chinese-trainer/admin.html), войти с fine-grained token GitHub для репозитория `chinese-trainer` с правом `Contents: Read and write`, выбрать JPG, PNG или WebP и опубликовать общий фон. Страница преобразует изображение в JPG, ограничивает большую сторону 1600 пикселями и отправляет его в репозиторий. Ключ используется только в памяти вкладки; после выхода или закрытия страницы требуется повторный вход.

Открытый адрес страницы управления не даёт право публикации. Изменения принимает GitHub только с действующим ключом, имеющим право записи в исходный репозиторий. Публичная страница управления дополнительно проверяет аккаунт `vs363ru`. Проверка прав публикации происходит на стороне GitHub; скрытие адреса не является защитой.

Вариант без ввода ключа в странице управления: войдите в GitHub под `vs363ru`, откройте [папку images](https://github.com/vs363ru/chinese-trainer/tree/main/images), выберите **Add file → Upload files** и загрузите готовый JPG с именем **reward.jpg**. Если такой файл уже есть, загрузите его замену с тем же именем. Зафиксируйте изменение кнопкой **Commit changes**. Изменения вступают в силу после завершения публикации GitHub Pages; затем обновите тренажёр.

Фотография размещается в публичном репозитории и доступна для просмотра и скачивания. Удаление текущего файла не удаляет его предыдущие версии из истории GitHub.

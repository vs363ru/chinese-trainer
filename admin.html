Вход владельца

Публикация доступна аккаунту GitHub vs363ru с правом записи в этот репозиторий.

Ключ используется только для GitHub и хранится в памяти этой вкладки. После закрытия страницы потребуется новый вход.

Как получить ключ
  1. Откройте создание fine-grained token в GitHub под аккаунтом vs363ru.
  2. Выберите владельца vs363ru, срок действия и Only select repositories → chinese-trainer.
  3. В Repository permissions установите Contents → Read and write. Другие права добавлять не требуется.
  4. Нажмите Generate token, скопируйте ключ и вставьте его в поле выше.

Также можно загрузить готовый JPG через папку images в GitHub под именем reward.jpg.

Владелец: vs363ru

Выберите фотографию или рисунок

JPG, PNG или WebP, до 20 МБ. Изображение будет уменьшено до 1600 пикселей.

После публикации обновление GitHub Pages может занять несколько минут. Фотография станет публичной.

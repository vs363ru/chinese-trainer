# Китайский вслух

Тренажёр 119 базовых китайских слов в одном файле `index.html`, без установки и сервера.

Открыть: https://vs363ru.github.io/chinese-trainer/

Раунд по каждому слову:
1. Программа произносит слово по-китайски.
2. Вы повторяете. Распознавание речи браузера (zh-CN) определяет, что прозвучало, а программа сверяет слоги и тоны через пиньинь и подсказывает, что поправить.
3. Вы говорите перевод по-русски (ru-RU), программа его проверяет.

Новые слова сначала показываются с переводом и спрашиваются через пару карточек. Ошибки возвращаются в конце раунда, выученные слова повторяются через 1, 3, 7 и 21 день. Прогресс хранится в браузере (localStorage).

## Где работает голос

| Устройство | Браузер | Голосовой режим |
|---|---|---|
| Компьютер | Chrome, Edge | да |
| Android | Chrome | да |
| iPhone, iPad, Mac | Safari | да; если микрофон не включается — проверьте, включены ли Siri и Диктовка |
| Firefox, встроенные окна приложений | — | нет, ответы вводятся с клавиатуры |

Браузер даёт микрофон только защищённой странице: надёжнее всего открывать её по HTTPS-ссылке. Распознавание идёт через серверы Google (Chrome) или Apple (Safari), поэтому нужен интернет.

## Ограничение проверки

Распознавание речи определяет, какое слово вы сказали, и опирается на языковую модель. Тон оно оценивает грубее, чем преподаватель: иногда «исправляет» неточный тон до правильного слова или, наоборот, слышит частое похожее слово. Поэтому после ошибки есть кнопка «Засчитать».

## Как добавить слова

Массив `RAW` в `index.html`: тема, иероглифы, слоги с номером тона (`5` — нейтральный, `_` — внутри слова), список допустимых переводов, пояснение.
